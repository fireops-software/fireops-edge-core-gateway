# FireOps-Edge Core Gateway
This component represents a gateway between fireops-edge and fireops-core. It is responsible for publishing information from fireops-core on local running rabbitmq instance, as well as notifing fireops-core about new incomming events from alu2g.

>**_NOTE:_** This component completly replace [fireops-edge-core-notifier](https://github.com/fireops-software/fireops-edge-core-notifier)!

## Configuration
All configuration is done via environmental variables because the intended form of running the project is in a Docker container.

| Variable | Default | Description |
|----------|---------|-------------|
| RABBITMQ_HOST |  | RabbitMQ host (e.g. 192.168.x.x or Hostname) |
| RABBITMQ_PORT | 5672 | RabbitMQ port |
| RABBITMQ_USER |  | RabbitMQ user |
| RABBITMQ_PW |  | RabbitMQ password |
| RABBITMQ_EVENTS_EXCHANGE | fireops-edge-events | RabbitMq exchange, that manage event notifications (old: alerts) |
| RABBITMQ_ALU2G_ACTIVE_ROUTINGKEY | alu2g.active | RoutingKey for active events comming from alu2g |
| RABBITMQ_ALU2G_NEW_ROUTINGKEY | alu2g.new | RoutingKey for new events comming from alu2g |
| RABBITMQ_ACTIVE_ROUTINGKEY | active | RoutingKey, where merged events will be published ( alu2g <-> fireops-core) |
| RABBITMQ_UNITS_EXCHANGE | fireops-edge-units | Exchange, where unit updates from fireops-core will be published |
| RABBITMQ_UNITS_ROUTINGKEY |  | RoutingKey for units exchange |
||||
| FIREOPS_BASE_URL |  | Base url for fireops-core api (e.g. https://einsatz.bfk-perg.at) |
| FIREOPS_TOKEN |  | Fireops-core accesstoken (can be generated by admin in online view) |
||||
| LOG_LEVEL | INFO | TRACE, DEBUG, INFO, WARNING, ERROR, FATAL, OFF |
